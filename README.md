# bond-pricing-tool

## Calculations Done in this Project
1. Periodic Coupon Payment: ex. $1000 bond at 5% coupon rate with 1 period a year would give $50 a payment
2. Newton-Raphson Method (NRM): For calculating the Yield-to-Maturity
3. Yield-to-Maturity (YTM): Creates an estimated YTM based on the given bond using 0.05 as a starting point passed to NRM
4. Discount Factor: Use bond info and YTM to calculate the discount factor for current period
5. Flat Curve Discount Rate: Uses the YTM and the other bond data to create the flat curve rate.
